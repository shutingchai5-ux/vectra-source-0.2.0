# 界面基础组件

全站使用 Element Plus 2.14.7 作为基础组件库，通过 `apps/web/src/components/ui.ts` 注册统一控件，`apps/web/src/ui.css` 维护绿色主题、字号、间距、边框、表格和反馈样式。组件按需引入对应样式及依赖，中文环境由根组件的 Config Provider 设置。

`apps/web/src/layout.css` 统一桌面页面的标题、概览、业务卡片与排版：正文及表单采用 14–15px，辅助说明以 12–13px 为主，侧栏保留全部导航和对话历史。概览区使用紧凑卡片，避免挤占车辆明细和车次操作区域。新增页面优先复用这些规则。

- `UiButton`：统一按钮外观，保留原表单提交、点击、禁用行为。
- `UiInput`：统一文本、数字、时间和多行输入，保留既有取值、输入事件与数字修饰。
- `UiSelect`：统一下拉框，将原选项与标签转换为组件库选项，保留空值代表“全部”的筛选语义。
- `UiFieldset`：向自定义表单控件传递禁用状态，保证保存、处理及只读模式生效。
- `UiAlert`、`UiTag`：统一信息反馈和业务状态。
- `UiTable`：为协议与原始材料保留语义表格结构，使用统一主题。离园确认列表使用 Element Plus Table 与 Pagination。

对话编辑器继续使用按内容扩展的输入区，对话布局、角色头像、协议报文、签名和公式排版各自保留业务组件。原生文件选择、复选框和单选框使用同一套主题色。新增页面应复用基础控件，不再复制整套按钮和表单样式。

对话使用页面滚动，每个实际交互单独展示身份、阶段、时间与状态；协作身份目录可以按需展开。Agent 卡片将身份名称、主／子身份和配置状态分行排列。报告页先选择任务、查看保存的业务结果与验证状态，完整报告原文保留在可展开区域；编辑原文后会清除上次验证结果，下载始终提供已保存的原始报告。

Vite 构建将 KaTeX 公式渲染拆成独立的 `math-renderer` 文件，页面功能继续按路由加载，避免基础组件接入后把主脚本继续堆大。

离园记录的用途是确认离园：待确认列表仅包含已结束作业且未记录离园时间的车次；打开页面、选择车辆均不产生离园事件。确认后保存当前上海时间，或用户填写的有效历史时间。列表和右侧面板只展示离园时间，完整生命周期、更正和历史导入移到全部记录。

依照 [Element Plus 快速开始](https://element-plus.org/en-US/guide/quickstart.html) 与 [全局配置](https://element-plus.org/en-US/component/config-provider.html) 接入。
